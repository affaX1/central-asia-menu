# Ресторанное меню

Электронное меню для ресторана: гость наводит камеру на QR-код на столе и видит меню на телефоне.

## Что умеет

- Категории сверху, при прокрутке подсвечивается текущая
- Поиск по блюдам (на всех языках сразу)
- Карточка блюда: описание, состав, аллергены, выход, калории
- Метки: Хит, Новинка, Острое, Без мяса
- «Мой заказ»: гость собирает список, сумма считается сама.
  Когда подключён сервер (SETUP.md) — гость жмёт «Отправить заказ» и видит статус: принят → готовится → подан
- Админка `admin.html` для сотрудников: заказы со столов приходят сразу со звуком, кнопки статусов, выручка за день
- 5 языков: русский, узбекский, английский, арабский (справа налево), малайский.
  Сначала открывается язык телефона гостя (если его нет в списке — английский), сменить можно кнопкой 🌐
- Светлая и тёмная тема
- Без подключённого сервера — просто страница, работает как обычное меню

## Как открыть

Двойной клик по `index.html`, он откроется в браузере.

## Как поменять меню

Всё меню лежит в одном файле: `data.js`. Там название ресторана, адрес, часы, валюта, категории и блюда.
Вверху файла написано, какое поле за что отвечает.

- Новое блюдо: скопировать любой блок блюда и поменять `id`, название, цену
- Убрать блюдо на время (стоп-лист): дописать `hidden: true`
- Фото вместо эмодзи: положить картинку в папку `photos/` и написать `photo: 'photos/имя.jpg'`

## QR-коды на столы

Открыть `print.html` с того адреса, где лежит меню, указать число столов и нажать «Печать».
На каждой карточке свой QR: он открывает меню с номером стола (`?table=5`).
Номер виден гостю сверху и крупно в «Моём заказе», официант сразу понимает, какой это стол.

Важно: QR ведёт на адрес из поля «Адрес меню». Печатать надо, когда меню уже лежит в интернете,
иначе с телефона гостя ссылка не откроется.

## После изменений

В `index.html`, `print.html` и `admin.html` у файлов стоит `?v=6`. После любой правки увеличь число (`?v=7`),
иначе телефоны гостей до 10 минут могут показывать старое меню.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | каркас страницы |
| `styles.css` | внешний вид |
| `app.js` | логика: поиск, заказ, языки, тема |
| `data.js` | **меню, менять тут** |
| `print.html` | QR-карточки на столы для печати |
| `admin.html`, `admin.js`, `admin.css` | админка для сотрудников |
| `config.js` | адрес и публичный ключ сервера заказов |
| `supabase/schema.sql` | таблицы и защита заказов, запускается в Supabase |
| `SETUP.md` | как подключить приём заказов, по шагам |
