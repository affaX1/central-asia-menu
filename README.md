# Central Asia Restaurant — электронное меню

Гость открывает меню на телефоне по QR-коду на столе, смотрит блюда и собирает список,
чтобы показать его официанту. Список **никуда не отправляется** — это подсказка для заказа.

## Три роли

| Кто | Где | Что может |
|---|---|---|
| Гость | `index.html` (по QR) | смотреть меню, собирать свой список на телефоне |
| Официант | `waiter.html` (вход) | видеть меню, цены и наличие, искать и фильтровать. Только чтение |
| Владелец | `owner.html` (вход) | менять меню, цены, наличие, фото, данные ресторана, расписание, сотрудников |

Права проверяет сервер (правила доступа в базе Supabase), а не скрытые кнопки:
официант не может ничего изменить даже прямым запросом — это проверяется тестами.

## Что есть в меню гостя

- Название, логотип (или монограмма), описание кухни, номер стола из QR (`?table=5`)
- «Открыто / Закрыто» по расписанию **и часовому поясу ресторана**: дни недели, выходные, работа после полуночи
- Часы работы по дням, адрес (открывается в картах), телефон (звонок) — пустые поля скрыты
- Поиск на всех языках, категории с подсветкой при прокрутке
- Карточки: фото (или аккуратная заглушка), название, описание, цена, выход, метки, наличие
- «Нет в наличии»: такое блюдо нельзя добавить; если закончилось уже в списке — гость видит предупреждение, сумма пересчитывается; так же при смене цены
- 5 языков: русский, узбекский, английский, арабский (справа налево), малайский; светлая и тёмная тема
- Состояния загрузки, ошибки сети, пустого поиска; работа с сохранённым меню без интернета
- Без эмодзи: единый набор векторных иконок

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html`, `app.js`, `styles.css` | меню гостя |
| `schedule.js` | расчёт «Открыто/Закрыто» (общий для сайта и тестов) |
| `data.js` | запасное меню, пока сервер не подключён (цены примерные) |
| `admin.html` | вход для сотрудников |
| `waiter.html`, `waiter.js` | меню для официанта |
| `owner.html`, `owner.js` | панель владельца |
| `staff-core.js`, `staff-api.js`, `staff.css`, `icons.svg` | общее для панелей |
| `print.html` | QR-карточки на столы |
| `config.js` / `config.example.js` | публичный адрес и ключ сервера |
| `supabase/schema.sql`, `supabase/seed.sql` | база, права, стартовое меню |
| `supabase/tests/`, `tests/`, `tools/` | тесты и генератор `seed.sql` |
| `SETUP.md` | как запустить сервер, по шагам |

## После изменений файлов

В `index.html`, `admin.html`, `waiter.html`, `owner.html`, `print.html` у файлов стоит `?v=7`.
После правки кода увеличьте число, иначе телефоны гостей до 10 минут могут показывать старую версию.
Изменения меню в панели владельца этого не требуют.
