# Central Asia Restaurant — электронное меню с заказом со стола

Гость сканирует QR-код на своём столе, открывает меню в браузере (без установки и регистрации),
собирает корзину и нажимает «Отправить заказ». Заказ сохраняется на сервере и сразу появляется
у официанта, повара и владельца. Гость видит номер и статус: «Отправлен» → «Подано» (когда официант
принёс заказ и нажал «Подано») или «Отменён». Шагов «принять / готовится / готово» нет.

## Три роли

| Кто | Где | Что может |
|---|---|---|
| Гость | `index.html?t=<код стола>` (QR) | смотреть меню, отправить заказ со своего стола, видеть статус **только своего** заказа |
| Официант | `waiter.html` (вход) | видеть заказы, которые ждут подачи, и отмечать **«Подано»**; меню, цены и наличие — только просмотр |
| Владелец | `owner.html` (вход) | входящие заказы и статусы, история, меню, цены, наличие, фото, столы и QR, данные ресторана, расписание, сотрудники |

Права проверяет сервер (правила доступа и функции в базе Supabase), а не скрытые кнопки.

## Как устроен заказ

- QR каждого стола содержит секретный код (`?t=…`). Сервер проверяет его; с неверного или отключённого QR заказ не создаётся.
- Перед отправкой меню перезагружается: если цена или наличие изменились, гость видит изменения и отправляет заново.
- Сервер ещё раз проверяет стол, блюда, наличие и цены и сам считает сумму. Подставить свою цену нельзя.
- Каждая попытка отправки несёт уникальный ключ: двойное нажатие или потерянный ответ сервера не создают второй заказ.
- «Заказ отправлен» гость видит только после подтверждения сервера; при ошибке сети — понятное сообщение и повтор.
- Заказ не принимается, если ресторан закрыт по расписанию (если владелец не разрешил иначе) или приём заказов выключен.
- Официант и владелец получают заказ сразу (Realtime): баннер, звук (после одного нажатия на странице), счётчик, заголовок вкладки, вибрация (Android), системное уведомление (по желанию).
- Если два официанта одновременно нажмут «Подано», ничего не сломается: заказ просто останется поданным.
- Номера заказов уникальные (с 1001). Отправленные заказы хранятся на телефоне отдельно от корзины; если сервер не знает заказ, он исчезает из списка.

## Что есть в меню гостя

- Название, логотип (или монограмма), описание кухни, номер стола (только подтверждённый сервером)
- «Открыто / Закрыто» по расписанию и часовому поясу ресторана: дни недели, выходные, работа после полуночи
- Часы работы, адрес (открывается в картах), телефон (звонок) — пустые поля скрыты
- Поиск на всех языках, категории, фото блюд или нейтральная заглушка, вес, цена, наличие
- Состав коротко: «**Конина** · рис, морковь, казы» — только если ресторан указал вид мяса и ингредиенты
- Значок «Халяль» — только если владелец его включил; данные сертификата — если внесены
- 5 языков: русский, узбекский, английский, арабский (справа налево), малайский; светлая и тёмная тема
- Состояния загрузки, ошибки сети, пустого поиска, пустой корзины; работа с сохранённым меню без интернета
- Без эмодзи: единый набор векторных иконок

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html`, `app.js`, `styles.css` | меню гостя |
| `schedule.js` | расчёт «Открыто/Закрыто» (общий для сайта и тестов) |
| `data.js` | запасное меню, пока сервер не подключён (цены примерные) |
| `admin.html` | вход для сотрудников |
| `waiter.html`, `waiter.js` | меню для официанта |
| `owner.html`, `owner.js` | панель владельца |
| `staff-core.js`, `staff-api.js`, `staff.css`, `icons.svg` | общее для панелей |
| `print.html` | старая ссылка — ведёт в «Столы и QR» панели владельца |
| `config.js` / `config.example.js` | публичный адрес и ключ сервера |
| `supabase/schema.sql`, `supabase/seed.sql` | база, права, стартовое меню |
| `supabase/tests/`, `tests/`, `tools/` | тесты и генератор `seed.sql` |
| `SETUP.md` | как запустить сервер, по шагам |

## После изменений файлов

В `index.html`, `admin.html`, `waiter.html`, `owner.html`, `print.html` у файлов стоит `?v=10`.
После правки кода увеличьте число, иначе телефоны гостей до 10 минут могут показывать старую версию.
Изменения меню в панели владельца этого не требуют.
